# MK Shop BD

Static e-commerce website for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — responsive design
- `script.js` — cart and WhatsApp ordering
- `images/` — product images supplied for the site
- `.nojekyll` — prevents unnecessary Jekyll processing

## GitHub Pages upload
1. Create/open the repository `mkshop`.
2. Upload the CONTENTS of this folder to the repository root. `index.html` must be in the root, not inside another `MK-Shop-BD` folder.
3. Commit the changes to `main`.
4. Go to Settings → Pages.
5. Under Build and deployment choose `Deploy from a branch`.
6. Branch: `main`; folder: `/(root)`; click Save.
7. Wait for the deployment to complete, then use Visit site.

If you get a red deployment error, open Settings → Pages → the failed deployment/workflow and check the error log.
